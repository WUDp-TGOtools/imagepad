# Microsoft Edge Add-ons listing: ImagePad

**Download:** Coming soon

**Name:** ImagePad
**Category:** Productivity
**Language:** English (default)

**Short description:**
Prepare images for upload beside any page: crop, blur, watermark, then drag into the site. Nothing is uploaded.

**Description:**
Same as the Chrome Web Store description (store/chrome-web-store.md). Edge opens ImagePad in the side panel when the browser supports it, and in a tab otherwise.

**Permissions and why:** side panel (editor), context menu (Edit with ImagePad), storage (settings).
**Privacy:** no data collected or transmitted.
**Support:** https://github.com/WUDp-TGOtools
